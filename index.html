About this utility

Juniper APK Delivery is a private-use developer utility intended to transfer Android preview APK builds from the owner's GitHub Actions workflow into a Google Drive folder selected by the account owner.

The utility is not a public APK distribution service. Google authorization is requested from the account owner before any upload. It does not publish Google Drive files or make them publicly accessible.

Automated delivery is under configuration and is not yet enabled.
