Purpose and data used

Juniper APK Delivery is a developer-controlled tool for uploading Android application packages (APKs) from GitHub Actions to the Google Drive account explicitly authorized by the owner. To perform this task, it may process Google OAuth access and refresh tokens, the destination folder identifier, APK file contents, build filenames, and upload results.

Use of Google information

Google authorization information is used only to authenticate the requested upload. The tool is not designed to read personal Drive documents, sell data, use Google data for advertising, or train AI models. OAuth credentials are intended to be stored as encrypted GitHub Actions secrets, not committed to source code.

Storage and sharing

APKs are stored in the owner's chosen Google Drive folder under that account's access controls. GitHub Actions may retain build artifacts according to repository workflow settings. Google and GitHub process information as necessary to provide their services. The developer does not intentionally disclose OAuth tokens or Drive files publicly.

Control and deletion

The owner may revoke Google access through Google Account security settings, remove GitHub Actions secrets, delete uploaded files from Drive, or disable the workflow. Existing uploaded files may need to be deleted separately.
